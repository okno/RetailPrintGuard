# Embedded receipt font

`DejaVuSansMono.ttf` is the unmodified DejaVu Sans Mono regular font, version
2.37, distributed by the Debian `fonts-dejavu-mono` package version 2.37-8.
Upstream: https://dejavu-fonts.github.io/ .

SHA-256: `54bf827eb99404e8f430c330ad30f063334f637eba0109b6a18d4f566a8e9dd8`

The 343,140-byte TrueType font was verified with ReportLab's font parser:
family `DejaVu Sans Mono`, PostScript name `DejaVuSansMono`, TrueType magic
`00010000`, euro glyph present. The copyright and complete Bitstream Vera
permission notice are retained in `LICENSE-DejaVu.txt`; DejaVu changes are
public domain. This font's license is distinct from the application license.

The PDF renderer embeds subsets and a Unicode mapping to preserve text without
depending on fonts installed on the reader's machine. The source scanner
permits only this exact asset and checksum; other binaries remain rejected.
